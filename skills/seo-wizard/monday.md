# SEO: понедельник

Цель: выбрать очередь недели из 3-5 задач с наибольшим эффектом.

1. Прочитай пакет: `seo_read_package` со `scenario = "monday"`.
2. Прочитай историю: `seo_read_history`.
3. Отметь свежесть данных: что собрано, что не настроено или упало.
4. Разбери `candidates`:
   - `high` и высокий `potential_score` сначала;
   - групповые проблемы по шаблону выше одиночных страниц;
   - ранее отклоненное не возвращай без новых данных.
5. Проверь `obscura_checks`. Если в текущей сессии доступна Obscura, открой только эти страницы и сохрани вывод в отчете. Если недоступна, отметь как проверку на ручной запуск.
6. Создай 3-5 задач через `seo_create_task_from_issue`.
7. Для решений `301/canonical/noindex/new_page/filter_policy` создай обычный inbox/decision request через инструменты MBOX, не задачу на внедрение.
8. Остальные находки:
   - `noise`, если это точно шум;
   - `rejected`, если история запрещает действие;
   - оставь `open`, если надо подождать данных.
9. Запиши отчет через `seo_record_session_report`.

Отчет должен содержать: свежесть, выбранные задачи, решения человеку, отложенное, что проверить через Obscura, риски.
