# Опыт навыка seo-wizard

Журнал самоулучшения. Пункт попадает в «Открытые», когда сессия споткнулась о что-то повторимое; разбирается на сессии 25 числа (`monthly.md`) или раньше, если у пункта повторов 3 и больше. Правила — в разделе «Самоулучшение» файла `SKILL.md`.

Формат пункта: `дата · тип · что произошло · доказательство · что менять · повторов: N`.
Типы: `данные` (источник устарел, упал, стоит денег), `шум` (детектор даёт лишнее), `итог` (изменение не помогло или ухудшило), `правило` (инструкция навыка мешает или неполная), `код` (нужна правка сервера — только задачей в MBOX, не правкой навыка).

## Сделано

- 2026-10-09 · правило · В `SKILL.md` и `monday.md` добавлено обязательное правило свежести позиций (пункт про Topvisor): находки по позициям не создают задач без даты проверки. Автоматического контроля нет — только инструкция, поэтому пункт 1 выше остаётся открытым до кодовой правки.
- 2026-10-09 · данные · Wordstat переведён на Yandex Search API (`searchapi.api.cloud.yandex.net/v2/wordstat`, ключ сервисного аккаунта, роль `search-api.webSearch.user`): старый `api.wordstat.yandex.net` отдавал чужой сертификат, OAuth-токен «Словолова» к новому API не подходит. Спрос собирается раз в месяц на запрос (`seo-wordstat.mjs`), повторный прогон в том же месяце квоту не тратит — это закрывает часть пункта про повторные обращения к API (по запросам Wordstat; остальные обращения не разбирались).
- 2026-10-09 · правило · Каждому отслеживаемому запросу добавлен потенциал (`seo-potential.mjs`, секция `query_potential` в `positions`): спрос × (CTR топ-3 − CTR текущей позиции) × достижимость. Коэффициенты достижимости (0.7 / 0.4 / 0.15 / 0.05) и пороги уровней — экспертные, их надо откалибровать на `seo_changes` после первых измерений.
- 2026-10-09 · данные · Квоты Wordstat API: 10 запросов в секунду и 100 в час (`search-api.wordstatRequestsPerSecond` / `PerHour`). Первый сбор упёрся в 429 после 28 запросов из 202. Теперь сбор идёт порциями по 90 с паузой между запросами, расписание добирает остаток раз в час (`topUpDemand`); пока спрос собран не для всех запросов, «видимость» в динамике позиций считается только по тем, у кого он есть, и сравнивать её с прошлыми проверками нельзя.
- 2026-10-09 · правило · Позиции Topvisor обновляются раз в неделю автоматически: сервер заказывает проверку (`edit/positions_2/checker/go`, `do_snapshots=0`, платные снимки не запрашиваются никогда), через 20 минут забирает результат, пишет журнал в `seo_rank_checks`. Реальная картина на 9 октября: в проверенной глубине 133 запроса из 202 против 179 на 3 августа, в топ-10 было 55, стало 32 (вышли 23, вошли 7). Причину (падение или аномалия проверки) ещё не разбирали — смотреть секции «Изменения» и «Гуляют страницы» в представлении позиций.
