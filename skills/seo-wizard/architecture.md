# SEO: архитектура, 10 число

Цель: индекс, sitemap, фильтры, состав страниц, каннибализация по разделам.

1. Прочитай пакет `scenario = "architecture"` и историю.
2. Проверь контрольные пункты: sitemap, технические адреса, туры `/tour?id=N`, lastmod, `/index.php`, H1 главной, одинаковые окончания URL.
3. Не предлагай менять плоскую структуру.
4. Для каннибализации предлагай только: развести интенты, переписать title/H1/содержание, canonical, внутренние ссылки на основную страницу, 301 для явных дублей через решение человека.
5. Запиши отчет и решения.
