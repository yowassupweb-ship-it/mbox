# Визуальный контракт письма

Это извлечённая система из `letter1.html`. Новое письмо не должно «похоже выглядеть» — оно должно пользоваться этими же значениями и пропорциями.

## Палитра

| Роль | Значение |
| --- | --- |
| Внешний фон | `#FFF6ED` |
| Поверхность письма и карточки | `#FFFFFF` |
| Акцент, основная кнопка, заголовки | `#FF732D` |
| Мягкий фон чередующейся карточки | `#FFF8F4` |
| Разделитель и граница карточки | `#FFE8D8` |
| Основной тёмный текст | `#2A2A2A` |
| Обычный текст | `#464646` |
| Вторичный текст маршрута | `#777777` |
| Мета-данные | `#BBBBBB` |
| Футер | `#7B7B7B` |
| Белый текст на акценте | `#FFFFFF` |

Не вводи новый фирменный цвет. Допустимы только прозрачные варианты акцента и тени, уже используемые в исходных блоках.

## Геометрия и ритм

- Рабочая ширина: до **660 px**, минимум **320 px**; внешний контейнер — `.em-narrow-table`.
- Внутренние отступы контента: **40 px** на десктопе, **20 px** на мобильном через классы `em-mob-padding_*`.
- Радиус внешнего контейнера: **35 px**; карточек и баннеров: **20 px**; круглых CTA/навигации: **25–50 px**.
- У карточек есть нижний акцент-тень `border-bottom: 3px solid rgba(140,40,0,.4)`; не заменяй её плоской кнопкой.
- В карточках тура изображение занимает около **48%** ширины. Ориентация карточек чередуется: image-left, затем image-right.
- На мобильном колонки становятся вертикальными через уже заданные `em-mob-wrap` и `em-mob-width-100perc`; не удаляй эти классы.

## Неподвижные правила email-вёрстки

- Структура — вложенные таблицы (`table`, `tr`, `td`), а не CSS Grid, Flexbox или JavaScript.
- Кликабельные изображения содержат `display:block`, явный `alt` и ссылку на тот же URL, что заголовок и CTA соответствующей карточки.
- Для кнопок сохраняй table-cell фон, радиус и нижнюю тень: это надёжнее в Outlook и почтовых клиентах.
- Не удаляй DOCTYPE, `meta charset`, viewport, `x-apple-disable-message-reformatting` и `format-detection`.
- В новом блоке не допускается HTML внутри CSS-значения: например `font-size:15px<br>` — это повреждённый артефакт базового письма.
