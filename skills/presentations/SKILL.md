# Презентации в MBOX

Презентация живёт в MBOX и открывается вкладкой: человек видит, как появляется и меняется каждый слайд.
Работай через MCP `mbox-prod`: `presentation_list`, `presentation_create`, `presentation_read`, `presentation_slide`,
`presentation_write`, `presentation_set_template`.

## Порядок работы

1. **Сначала стиль человека.** `presentation_list(templates=true)`. Если шаблоны есть — выбери подходящий по теме
   и создай презентацию из него (`presentation_create(template_id=…)`), затем `presentation_read`, чтобы увидеть тему,
   расположение блоков и размеры шрифтов. Шаблонов нет — посмотри 1–2 последние презентации (`presentation_list`)
   и повтори их тему и раскладку. Ничего нет — начни с пустой (`presentation_create`).
2. **Открой человеку.** `presentation_create(show=true)` открывает вкладку сам; правки видны сразу.
3. **Слайд за слайдом.** Каждый слайд — отдельный вызов `presentation_slide(op="add"|"update")`. Не собирай всё
   одним `presentation_write`: человек должен видеть ход работы и успеть поправить.
4. **Проверь.** `presentation_read` в конце: блоки внутри слайда, текст не вылезает, на слайде одна мысль.
5. **Закрепи стиль.** Если человек доволен видом — предложи сделать презентацию шаблоном (`presentation_set_template`).

## Модель слайда

Слайд 960×540 пикселей. `{ background?, notes, elements: [...] }`, элементы расположены свободно:

- `text`: `{ type: "text", role: "title"|"subtitle"|"body", x, y, w, h, html, style: { fontSize, color, align, valign, bold, italic } }`.
  `html` — только `<b> <i> <u> <br> <ul><li> <div>`.
- `shape`: `{ type: "shape", shape: "rect"|"round"|"ellipse"|"line", x, y, w, h, fill, stroke, strokeWidth, html? }`.
  Цвет с прозрачностью — `#RRGGBBAA`.
- `image`: `{ type: "image", x, y, w, h, src: "https://…", fit: "cover"|"contain", radius?, opacity? }`. Картинку на весь
  слайд под текстом ставь первой в `elements`, `x:0, y:0, w:960, h:540`.

Тема (`op="theme"`): `fontFamily, background, text, accent, titleSize, bodySize`. Цвет текста без `style.color` берётся из темы.

Опорная раскладка: заголовок `x:60, y:40, w:840, h:90`, текст `x:60, y:150, w:840, h:330`; две колонки по `w:400`
с `x:60` и `x:500`; поля не меньше 40 px.

## Правила хорошего слайда

- Одна мысль на слайд, заголовок — вывод, а не тема («Выручка выросла на 18%», а не «Выручка»).
- Не больше 5 пунктов и 8–10 слов в пункте; подробности — в `notes` (заметки докладчика).
- Размер текста не меньше 18, заголовок 36–48. Контраст текста и фона — читаемый.
- Цифры и факты — только из данных человека или MBOX; не выдумывай.

## Подстройка под человека

Когда человек поправил слайд, цвет, шрифт или подачу, отказался от варианта или сказал «всегда/никогда» — запиши правило
через `skill_learning_add(id="presentations", text=…)`. Перед новой презентацией правила уже лежат в learnings.md.
