# Запрос 2: система и управление MBOX

Продолжи приложенную утверждённую серию и создай 10 новых интерфейсных иконок MBOX. Приложенные иконки первого пакета — обязательный style reference: сохрани их геометрию, толщину деталей, перспективу, цветовой баланс и оптический вес. Не придумывай новый стиль.

Каждый результат — отдельный PNG 512 × 512 px, RGBA, sRGB, прозрачный фон. Не коллаж и не sprite sheet. Human Interface, округлая чистая геометрия, две-три цветовые плоскости, без pixel art, emoji, текста, фоновой плашки, шума и тяжёлых теней. Силуэт занимает 72–76% холста, безопасное поле 56 px, линии не тоньше 14 px. Палитра: графит, молочный белый, `#69DCC8`, `#7C8CFF`. Читаемость на `#F5F5F7`, `#202124`, `#050506` и при 24 px.

1. `console.png` — окно терминала с крупным знаком ввода и короткой линией результата; без читаемого кода.
2. `history.png` — разомкнутая круговая стрелка вокруг одной временной отметки.
3. `settings.png` — простая шестилепестковая шестерня с крупным центром.
4. `graph.png` — пять узлов и четыре связи с одним акцентным центральным узлом.
5. `todo.png` — пустой квадратный чекбокс рядом с двумя крупными строками.
6. `git.png` — узнаваемая схема ветвления из трёх узлов в духе Git; без слова Git.
7. `figma.png` — узнаваемый пятидольный знак Figma, адаптированный к стилю серии; без слова Figma.
8. `relations.png` — два равнозначных объекта, соединённых двунаправленным мостом.
9. `properties.png` — три горизонтальных регулятора с крупными бегунками.
10. `philosophy.png` — спокойная призма, разделяющая один луч на три; без религиозных знаков.

Верни ровно 10 отдельных файлов с указанными именами. Если возможна только последовательная генерация, используй один seed и приложенные референсы для всех десяти.
