# Визуальный референс серии

Прикладывайте к запросам 02–04 все три PNG из этой папки:

- `overview.png` — задаёт плотность сложной составной иконки;
- `artifacts.png` — задаёт чистоту геометрии и баланс цветов;
- `storage.png` — задаёт мягкий объём и работу с белыми поверхностями.

Новые изображения должны продолжать этот стиль, а не интерпретировать его заново. Файлы здесь являются копиями принятых мастер-кандидатов первого пакета.
