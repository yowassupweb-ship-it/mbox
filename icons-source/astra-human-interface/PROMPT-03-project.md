# Запрос 3: действия и сущности MBOX

Продолжи приложенную утверждённую серию и создай 10 новых интерфейсных иконок MBOX. Приложенные принятые иконки — обязательный style reference. Сохрани точную пластику, перспективу, толщину деталей, насыщенность и оптический вес серии.

Каждый результат — отдельный PNG 512 × 512 px, RGBA, sRGB, прозрачный фон. Не коллаж. Стиль Human Interface, чистые округлые формы, две-три цветовые плоскости. Без pixel art, emoji, персонажей, текста, фоновой плашки, фотореализма и тяжёлых теней. Силуэт 72–76% холста, безопасное поле 56 px, линии не тоньше 14 px. Палитра: графит, молочный белый, `#69DCC8`, `#7C8CFF`; семантический цвет только по смыслу. Проверить светлый, графитовый и чёрный фон, а также размер 24 px.

1. `deploy.png` — компактная ракета, выходящая вверх из двух спокойных дуг; без огненного взрыва.
2. `stack.png` — три смещённые пластины, собранные в устойчивую стопку.
3. `access.png` — щит с крупной замочной скважиной; не полицейский значок.
4. `sources.png` — три входящих потока, сходящихся в один документ.
5. `folder.png` — закрытая одиночная папка, фронтальный вид; проще `folders.png`.
6. `documents.png` — два листа со смещением, на переднем две крупные строки.
7. `posts.png` — карточка материала с крупным изображением и двумя строками.
8. `add.png` — крупный плюс, объединённый с маленькой папкой.
9. `ssh.png` — терминальное окно, соединённое защищённым каналом с удалённым узлом; без букв SSH.
10. `check.png` — уверенная галочка с мягкими окончаниями, без окружности.

Верни ровно 10 самостоятельных PNG с точными именами. При последовательной генерации не меняй seed, style reference и параметры.
