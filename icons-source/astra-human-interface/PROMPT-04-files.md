# Запрос 4: сценарии и типы файлов MBOX

Заверши приложенную утверждённую серию десятью интерфейсными иконками MBOX. Приложенные принятые иконки предыдущих пакетов — обязательный style reference. Новые файлы не должны выглядеть отдельным набором.

Каждый результат — отдельный PNG 512 × 512 px, RGBA, sRGB, прозрачный фон. Не коллаж и не таблица. Human Interface, чистая округлая геометрия, одинаковый оптический вес, две-три цветовые плоскости. Без pixel art, emoji, текста, буквенных расширений, фоновой плашки, шума и тяжёлых теней. Силуэт 72–76% холста, безопасное поле 56 px, линии не тоньше 14 px. Палитра: графит, молочный белый, `#69DCC8`, `#7C8CFF`. Читаемость на светлом, графитовом и чёрном фоне, в том числе при 24 px.

1. `scenarios.png` — три последовательные карточки, соединённые маршрутом с одной развилкой.
2. `image-file.png` — лист с крупным силуэтом горы и солнца.
3. `code-file.png` — лист с крупными угловыми скобками; без читаемого кода.
4. `archive-file.png` — плотная коробка с центральной застёжкой-молнией; без букв ZIP.
5. `link-file.png` — лист с двумя крупными соединёнными звеньями.
6. `table-file.png` — лист с простой сеткой 3 × 3 и одной акцентной ячейкой.
7. `presentation-file.png` — экран на стойке с одной крупной диаграммой.
8. `pdf-file.png` — лист с плавным контуром ленты Acrobat, без букв PDF и без полного копирования логотипа Adobe.
9. `email-file.png` — раскрытый конверт с видимым листом; без значка уведомления.
10. `browser-file.png` — окно браузера с крупным заголовочным блоком и двумя секциями; без адреса и текста.

Верни ровно 10 отдельных PNG с указанными именами. Если генерируешь последовательно, сохрани один seed, reference и параметры до конца пакета.
