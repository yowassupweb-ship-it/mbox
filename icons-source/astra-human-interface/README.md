# Иконки MBOX для Astra

Эта папка — единая точка приёма новых непиксельных иконок MBOX.

## Как работать

1. Отправьте Astra файл `PROMPT-01-navigation.md` целиком.
2. Полученные отдельные PNG положите в `masters/batch-01-navigation` с точными именами из задания.
3. Выберите 2–3 наиболее удачные иконки первого пакета и прикладывайте их к следующим запросам как визуальный референс. Не просите Astra менять стиль между пакетами.
4. По очереди отправьте `PROMPT-02-system.md`, `PROMPT-03-project.md` и `PROMPT-04-files.md`.
5. Складывайте результаты в соответствующие папки `masters/batch-*`.
6. Не заменяйте действующие иконки приложения до общей приёмки всей серии.

## Куда класть файлы

```text
masters/
├── batch-01-navigation/  10 PNG
├── batch-02-system/      10 PNG
├── batch-03-project/     10 PNG
└── batch-04-files/       10 PNG
```

Каждый мастер-файл должен быть `512 × 512 px`, `PNG`, `RGBA`, `sRGB`, с прозрачным фоном. Имена только ASCII и строго по заданию. Astra не должна отдавать коллаж, сетку, мокап или один файл с десятью объектами.

Если Astra не умеет вернуть десять вложений за один ответ, она должна последовательно создать десять изображений, сохраняя один seed, один style reference и одинаковые параметры. Один файл всё равно содержит только одну иконку.

Полное ТЗ и карта старых имён находятся в [docs/astra-icons-briefs.md](../../docs/astra-icons-briefs.md).

## Статус пакетов

- `batch-01-navigation`: получен полностью, 10 из 10 мастер-файлов; канонические имена назначены.
- Исходный квадратный размер Astra `1254 × 1254 px` сохраняется как мастер. Уменьшенные рабочие версии будут собраны отдельно после приёмки всей серии.
- Результаты проверки первого пакета записаны в [`masters/batch-01-navigation/QA.md`](masters/batch-01-navigation/QA.md).
- Для следующих запросов прикладывайте три изображения из [`style-reference`](style-reference) как обязательный визуальный ориентир.
