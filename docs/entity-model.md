# MBOX Entity Model

MBOX делится на рабочие сущности, чтобы человеку и AI-агентам было понятно, где искать и куда сохранять данные.

## Access Levels

- `private`: личная зона владельца, не экспортируется агентам.
- `agents`: безопасная зона для Claude и ChatGPT.
- `public`: можно отдавать внешним агентам и интеграциям.

## Core Entities

- `memory`: строка базы памяти, отображается таблицей и индексируется.
- `project`: папка проекта.
- `todo`: задачи и заметки проекта, редактируемые с ПК и телефона.
- `artifact`: готовое решение, компонент, конфиг или скрипт.
- `script`: обслуживающий сценарий для уборки, сортировки, индексации и экспорта.
- `graph_edge`: связь между сущностями.

## Maintenance Logic

- `cleanup`: дубли, пустые теги, битые связи.
- `sort`: раскладка сущностей по папкам.
- `index`: полнотекстовый индекс, графовые связи, будущий vector index.
- `agent-export`: только `agents` и `public`, без приватных заметок и секретов.
