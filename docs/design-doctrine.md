# Доктрина дизайна MBOX

Свод правил, по которым выглядит и ведёт себя интерфейс MBOX: веб (mbox.shar-os.ru), MBOX Desktop
(Electron) и мобильная раскладка. Источник истины для значений — `src/styles/tokens.css`; этот
документ объясняет, **какой токен брать и почему**, и фиксирует решения, которые в коде видны только
по комментариям.

Если правило здесь расходится с CSS — сначала выясни, что устарело, и поправь одно из двух. Молча
жить с расхождением нельзя.

---

## 1. Характер

MBOX — рабочее место человека и его AI-агентов: заметки, проекты, память, чат, браузер, терминал.
Интерфейс собран из двух традиций:

- **Раскладка VS Code.** Шапка, полоса разделов, боковая панель, вкладки редактора, нижняя панель,
  строка состояния. Всё помещается в один экран; прокручиваются только области, окно — никогда.
- **Отделка macOS (Human Interface).** Мягкая геометрия, пилюли, сегменты вместо подчёркнутых
  ярлыков, полупрозрачные меню, обычный регистр в заголовках, спокойная типографика Inter.

Из этого следуют четыре принципа:

1. **Инструмент, а не витрина.** Плотность выше, чем у маркетингового сайта: основной кегль обвязки —
   13px, строки дерева и вкладки невысокие. Декор не добавляется ради декора.
2. **Одна вещь ведёт.** На экране одно основное действие (заливка `--accent-fill`), остальное —
   ghost или значки. Две синие кнопки рядом — ошибка.
3. **Смысл, а не цвет.** Компоненты берут только семантические токены (`--text-muted`,
   `--state-warn`), никогда hex. Темы меняют значения токенов, а не правила компонентов.
4. **Каждое состояние видно.** Наведение, фокус с клавиатуры, активное, выбранное, отключённое,
   загрузка, пусто, ошибка — у любого интерактивного элемента.

## 2. Архитектура стилей

### 2.1 Файлы и порядок

Точка входа — `src/styles.css`. Порядок `@import` значим: каждый следующий слой перекрывает
предыдущий.

| # | Файл | Слой | Что в нём |
| --- | --- | --- | --- |

| 6 | `agents.css` | Агенты | аватары, статусы, ростер |
| 7 | `tree.css` | Дерево | дерево папок |
| 8 | `pages.css` | Экраны | отдельные страницы |
| 9 | `control-panel.css` | Панель управления | |

| 13 | `electron-performance.css` | Desktop | выключение blur и переходов в Electron |
| 14 | `hig.css` | **Отделка macOS** | геометрия, фокус, меню, диалоги, типографика `.wb` |
| 15 | `browser.css` | Браузер | вкладка-браузер |
| 16 | `catalog.css` | Каталоги | |
| — | `spotlight.css` | Поиск Spotlight | палитра Ctrl+K: поле, группы результатов, предпросмотр |
| 17 | `chrome.css` | Шапка и статус-бар | unified toolbar, строка состояния |
| 18 | `editor.css` | Редактор | |
| 19 | `mobile.css` | **Телефон ≤720px** | нижняя капсула-меню, одна область за раз |

Правила:

- **Новые переменные — только в `tokens.css`.** Исключение: размеры каркаса `--wb-*` в `.wb`
  (`workbench.css`) и мобильные `--wb-nav-*` (`mobile.css`) — это геометрия раскладки, не тема.
- **`hig.css` не трогает раскладку.** Только то, как элементы выглядят и ощущаются. Сетка, размеры
  областей — в `workbench.css`.
- **Новый компонент — в файл своей области**, а не в конец `hig.css`. `hig.css` — слой отделки,
  а не свалка.
- Не поднимай специфичность ради победы над соседом: сначала проверь порядок импорта.

### 2.2 Три уровня токенов

```
примитивы (hex, px)          →  семантика (смысл)             →  компонент / контекст
#4da3ff, #0071e3, 12px           --accent-color, --accent-fill     --wb-selected, --note-mark,
                                 --text-muted, --radius-md         --kind-accent, --agent-accent
```

- Примитивные значения живут **только** внутри блоков тем в `tokens.css`.
- Компоненты читают семантику. Контекстные переменные (`--wb-hover`, `--note-mark`, `--doc-bg`)
  — алиасы семантики, которые локально переопределяются (например, тема документа).
- Hex в компоненте допустим только в двух случаях: превью тем (`.theme-preview.is-*` — рисует
  саму тему) и `color-mix(... #000)` для затемнения кромки. Всё остальное — долг (см. §13).

Графита»: у неё свои акцент и цвета состояний, потому что тёмные значения на белом не проходят
контраст (зелёный `#35c759` на белом — ниже 2:1).

### 3.1 Темы документа

Лист заметки/документа может иметь свою тему независимо от темы интерфейса: классы
`.doc-theme-light`, `.doc-theme-graphite`, `.doc-theme-black` (в `workbench.css`) локально
переопределяют `--text-main`, `--text-2`, `--text-muted`, `--wb-line`, `--wb-surface`, `--code-*`
значениями из `--doc-{light|graphite|black}-*`. Холст за листом — `color-mix(--doc-bg 93%, #000)`,
чтобы центрированная колонка читалась как страница, а не как текст в пустоте.

### 3.2 Desktop (Electron)

`:root[data-mbox-desktop="true"]` выключает размытие: `--blur-glass: 0px`, `--glass` становится
сплошным `--surface-panel`. Причина — скорость и то, что полупрозрачное меню без blur просвечивает
текстом. **Любой новый стеклянный элемент обязан выглядеть прилично без blur.**

## 4. Цвет

### 4.1 Роли

| Роль | Токен | Когда |
| --- | --- | --- |
| Фон окна | `--bg-color` | `html`, `body`, каркас `.wb` |
| Карточка, контейнер | `--container-bg` | вложенные блоки на фоне |
| Контрол | `--element-bg` | поля, ghost-кнопки, строки списков |
| Приподнятое | `--bg-raised` | активная вкладка, активный сегмент |
| Утопленное | `--bg-sunken` | колодцы, области кода |
| Обвязка | `--surface-chrome` → `--wb-surface` | шапка, строка состояния, полоса разделов |
| Панели | `--surface-panel` → `--wb-surface-2` | боковые панели, диалоги |
| Наведение | `--surface-hover` → `--wb-hover` | фон строки/кнопки под курсором |
| Выбрано | `--surface-selected` → `--wb-selected` | активная строка дерева, раздел |
| Основной текст | `--text-main` | заголовки, содержимое |
| Вторичный | `--text-2` | подписи, заголовки разделов |
| Приглушённый | `--text-muted` | метаданные, плейсхолдеры, строка состояния |
| Граница | `--border-color` / `--wb-line` | кромки 1px |

### 4.2 Акцент: две роли, два токена

Это главное цветовое решение MBOX (2026-09-25):

- **`--accent-color`** — акцент *как текст и линия*: ссылки, активные вкладки, кольцо фокуса,
  выделение, иконки состояния «вкл». На тёмном `#4da3ff`, на светлом `#0066cc`.
- **`--accent-fill`** + **`--on-accent`** — акцент *как заливка под текстом*: основная кнопка,
  подсветка пункта меню, primary в диалогах. `#0071e3` с белым текстом.

Белый текст на `#4da3ff` — 2.63:1, провал. **Никогда не заливай `--accent-color` под текст.**
Для полупрозрачных плашек используй `color-mix(in srgb, var(--accent-fill) 18%, transparent)`
с текстом `--accent-color` (как `.wb-browser-agent`).

`--accent-2`, `--accent-chin`, `--accent-edge`, `--eyebrow` — наследие прежнего «терминального»
языка; в новом коде не использовать, кроме `--eyebrow` для надзаголовков.

### 4.3 Состояния

| Токен | Смысл | Не путать с |
| --- | --- | --- |
| `--state-ok` / `--state-ok-soft` | успех, «сделано», агент активен | акцентом: зелёный ≠ «интерактивно» |
| `--state-live` | идёт процесс, работает сейчас | |
| `--state-warn` | требует внимания | |
| `--state-danger` | ошибка, удаление, «нет» | |
| `--state-off` | выключено, офлайн | |

Цвет состояния никогда не единственный носитель смысла: рядом значок или слово.
Тоны чипов — `.meta-chip.tone-{ok|live|warn|danger}`. Фон баннера/плашки состояния —
`color-mix(var(--state-X) 12–16%, var(--container-bg))`, рамка — `34%`.

### 4.4 Метки заметок

Восемь цветов: `--note-red #ff6b6b`, `--note-orange #ff9f43`, `--note-yellow #f6c945`,
`--note-green #52c878`, `--note-cyan #45c6c8`, `--note-blue #5a9cff`, `--note-purple #a783ff`,
`--note-gray #9298a3`. Ставятся через `data-note-color` → `--note-mark`. Отображение по правилу
`hig.css`: **точка 8px слева от заголовка**, а не полоса во всю высоту и не заливка строки.
Эти цвета — категории, а не состояния: не использовать их для ok/warn/danger.

### 4.5 Код

`--code-bg` (фон инлайна и блоков), `--code-text` (инлайн-код), `--code-block-text` (```-блоки).
На светлом: `#0b6b63` / `#1f2937`. Хардкодить цвет кода запрещено — мятный на белом листе
почти не читался, поэтому это токены.

### 4.6 Акценты сущностей и агентов

- `--kind-accent` — цвет типа сущности (проект, заметка, навык) внутри плитки/вкладки настроек;
  используется в рамке при наведении: `color-mix(var(--kind-accent) 40%, var(--border-color))`.
- `--agent-accent` — цвет агента на аватаре и в пульсе. Статусы аватара: активен — зелёный,
  ожидает — жёлтый, работает — голубой, офлайн — серый (сейчас числами в `agents.css`, см. §13).

## 5. Типографика

### 5.1 Семейства

- **`--font-sans`** — Inter Variable (100–900, прямой и курсив), лежит локально в
  `public/fonts/`, без CDN. Фолбэк: системные SF / Segoe UI Variable.
- **`--font-mono`** — JetBrains Mono → Cascadia Mono → SF Mono → Menlo → Consolas. Для кода,
  терминала, путей, `kbd` внутри `.wb`.
- `--font-pixel` — мёртвый алиас на sans, не использовать.

На корне включены `font-feature-settings: "cv05", "cv08", "calt"` — «l» с хвостиком и «I» с
засечками, чтобы l / I / 1 не путались в путях и названиях. `font-synthesis: none` — никаких
фальшивых жирных/курсивов.

### 5.2 Шкала

Размеры пишутся **только токенами**, никогда числом.

| Токен | px | Назначение |
| --- | --- | --- |
| `--text-2xs` | 11 | счётчики, `kbd`, мета заметки |
| `--text-xs` | 12 | подписи полей, строка состояния, метаданные, заголовки групп |
| `--text-sm` | 13 | **обвязка**: дерево, вкладки, кнопки, списки, тело `.wb` |
| `--text-md` | 14 | основной текст, чат, поля ввода, заголовок диалога |
| `--text-reading` | 15 | колонка чтения заметок и документов |
| `--text-lg` | 16 | заголовок раздела/панели |
| `--text-xl` | 20 | заголовок документа |
| `--text-2xl` | 26 | крупный заголовок страницы, число метрики |

Веса: `--weight-normal 400`, `--weight-medium 500`, `--weight-semibold 600`, `--weight-bold 650`.
Интерлиньяж: `--leading-tight 1.3` (заголовки), `--leading-normal 1.5` (интерфейс),
`--leading-reading 1.65` (чтение).

### 5.3 Правила

- **Регистр обычный.** ЗАГЛАВНЫЕ с разрядкой — язык VS Code и терминала; в MBOX заголовок
  раздела — короткая приглушённая строка полужирным (`--text-xs`/`--text-sm`, `--weight-semibold`,
  `--text-2`). `hig.css` снимает `text-transform` с заголовков боковых панелей.
- Жирным в боковой панели бывает только заголовок раздела. Имена проектов — `--weight-medium`.
- Заголовкам `h1–h3` в `.wb` — `letter-spacing: -0.01em`; крупным (`--text-2xl`) — до `-0.025em`.
- Числа в метриках и таблицах — `font-variant-numeric: tabular-nums`.
- Длинные однострочные названия — `overflow: hidden; text-overflow: ellipsis; white-space: nowrap`
  с `min-width: 0` у flex/grid-родителя.
- Русская типографика: тире «—», кавычки «ёлочки», неразрывный пробел перед тире. Тире — не
  «AI-признак», гейт `check_no_emoji.py` в этой части не применяется.

## 6. Пространство

### 6.1 Отступы

Шаг 4px:

| `--space-1` | `--space-2` | `--space-3` | `--space-4` | `--space-5` | `--space-6` | `--space-7` | `--space-8` |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 4 | 8 | 12 | 16 | 20 | 24 | 32 | 44 |

- Новые правила пишут отступы токенами. Старые файлы полны чисел (14px, 18px) — при правке
  соседнего правила переводи на ближайший токен, если это не ломает выравнивание.
- Внутренний отступ карточки/панели — `--space-4`…`--space-5`; зазор сетки — `--space-3`…`--space-4`;
  зазор внутри тулбара — `--space-2`.
- Строки дерева и заметок стоят **внутри поля** с отступом 6–8px от краёв панели, а не во всю
  ширину: выделение — скруглённая плашка.

### 6.2 Радиусы

| Токен | px | Кому |
| --- | --- | --- |
| `--radius-2xs` | 4 | подсветка выделения чужого курсора, мелкие метки |
| `--radius-xs` | 6 | `kbd`, пункты статус-бара, пункты мелких меню |
| `--radius-sm` | 8 | строки дерева, пункты меню, кнопки шапки, подсказки |
| `--radius-md` | 12 | меню и поповеры, многострочные поля, плитка иконки метрики, вложения |
| `--radius-lg` | 16 | карточки, панели, элементы списков |
| `--radius-xl` | 22 | диалоги, композер чата, метрики |
| `--radius-pill` | 999 | всё, что нажимают или во что пишут одной строкой |

**Правило геометрии (одно на весь интерфейс):**

- кнопки с текстом, чипы, бейджи, счётчики, однострочные поля, вкладки, сегменты — **пилюля**;
- кнопки-значки — **круг** (пилюля квадратного размера);
- кнопки на панели шапки — **скруглённый квадрат** `--radius-sm` без рамки (как тулбар macOS);
- карточки и панели — `--radius-lg`; меню — `--radius-md` с пунктами `--radius-sm`;
- диалоги и композер — `--radius-xl`.

Вложенный радиус меньше внешнего на величину отступа: меню 12 → пункт 8 при паддинге 5–6px.

### 6.3 Каркас рабочего места

`.wb` — CSS grid на весь `100dvh`, окно не прокручивается никогда.

```
┌──────────────────────── title (--wb-titlebar 38px) ────────────────────────┐
│ activity │ sidebar            │ center (вкладки + документ)   │ right      │
│ 64px     │ --wb-sidebar       │ minmax(0, 1fr)                │ --wb-right │
└──────────────────────── status (--wb-status 22px) ─────────────────────────┘
```

- `--wb-titlebar: 38px` **нельзя менять**: на Windows кнопки окна рисуются поверх шапки
  (`titleBarOverlay`, height 38 в `mbox-desktop/main.js`).
- `--wb-activity`: 44px в `workbench.css`, 64px после `hig.css` (кнопки 52×52, иконки 38×38).
- Полоса вкладок редактора — 38px, вкладка 28px.
- Любая колонка-потомок сетки — `min-width: 0` / `min-height: 0`, иначе прокрутка не включается
  и контент выдавливает соседей.
- Широкое содержимое (таблицы, код) крутится внутри своего контейнера (`.table-wrap`), страница —
  никогда. `body { overflow-x: hidden }`.

### 6.4 Слои (z-index)

Сейчас значения разбросаны от 1 до 400. Для нового кода — лестница:

| Уровень | z-index |
| --- | --- |
| Внутри компонента (бейдж, ручка) | 1–5 |
| Липкие шапки внутри областей | 10–20 |
| Каркас поверх содержимого (оверлеи панелей) | 30–50 |

## 7. Глубина: границы, тени, стекло

- **Кромка важнее тени.** Элементы читаются по контуру 1px `--border-color`, а не по размытой тени.
  `--container-inset` (`inset 0 0 0 1px`) — рамка, не занимающая место.
- `--chin-shadow` (`0 1px 2px`) — единственная тень для контролов и карточек в покое.
- Активная вкладка/сегмент: `--bg-raised` + `0 0 0 1px var(--border-color), 0 1px 2px rgba(0,0,0,.14–.18)`.
- `--shadow-sm|md|pop` — парящие мелочи (метка курсора коллеги, поповер, предпросмотр); `--danger-fill(-hover)` — заливка разрушительной кнопки. Белая «бумага» документа — `--paper-*`.
- `--float` — всё, что парит: диалоги, крупные поповеры.
- **Стекло** — только для парящих элементов (меню, пикеры, мобильная капсула): `--glass`,
  рамка `--glass-brd`, `backdrop-filter: blur(var(--blur-glass)) saturate(1.6)`, тень `--glass-shadow`.
  В Desktop стекло сплошное (§3.2). Карточки, панели, шапка — не стекло.
- `--accent-shadow` / `--green-shadow` — цветное свечение; использовать очень редко, только для
  одного «героя» на экране.

### 7.1 Присутствие коллег

Курсор, выделение и ячейки коллеги красятся цветом человека (`--peer`, палитра из восьми, один цвет на пользователя),
метка с именем — `--text-2xs`, `--radius-xs`, текст `--on-accent`. Слои лежат поверх редактора (`.wb-presence-layer`,
`pointer-events: none`) и никогда не перехватывают ввод. Правка агента подсвечивает диапазон 5 с и мигает. Аватары
в шапке — `PresenceAvatars`. Класс стрелки дерева — `.wb-caret`; курсор коллеги в тексте — `.wb-rcaret`, не путать.

## 8. Движение

| Токен | Значение | Когда |
| --- | --- | --- |
| `--duration-fast` | 0.12s | наведение, цвет рамки, нажатие |
| `--duration-base` | 0.2s | смена темы документа, раскрытие |
| `--ease-out` | `cubic-bezier(.25,1,.5,1)` | всё интерфейсное по умолчанию |
| `--ease-spring` | `cubic-bezier(.22,1,.36,1)` | появление поповеров и меню |

Правила:

- Переходы перечисляются явно (`transition: border-color …, background …`). **Никогда
  `transition: all`** — в Desktop это давало «липкий» авторазмер поля.
- Анимируем `transform`, `opacity`, цвета. Не анимируем ширину/высоту/top/left.
- Подъём на наведении (`translateY(-1px)`) — только одиночным плиткам. В горизонтальных рядах
  (плитки проектов) — только смена цвета рамки, иначе ряд «дёргается».
- `prefers-reduced-motion: reduce` гасит все переходы и анимации глобально (`base.css`).
  Новая бесконечная анимация (пульс, спиннер) обязана иметь свой reduced-motion-вариант.
- Нажатие: `translateY(1px)` или смена фона на `+5%` — без масштабирования.

## 11. Восемь состояний

Каждый интерактивный элемент проектируется во всех:

| Состояние | Как выглядит |
| --- | --- |
| Покой | токены роли |
| Наведение | `--surface-hover` / `--wb-hover`, либо рамка `+40%` акцента сущности; primary — `--accent-fill-hover` |
| Фокус с клавиатуры | кольцо `0 0 0 3px color-mix(--accent-color 45%)` (`hig.css`, `:focus-visible`), без `outline` |
| Нажатие | `translateY(1px)` или фон `+5%` |
| Выбрано / активно | `--surface-selected` / `--bg-raised` + кромка |
| Отключено | `opacity: .68`, без hover, `cursor: default` |
| Загрузка | текст-процесс («Сохраняю»), спиннер-осьминог для экранов, `aria-busy` |
| Ошибка / пусто | тон `danger` + текст по формуле «что случилось → почему → что сделать»; пустое состояние с одним действием |

Фокус только по `:focus-visible` — мышь кольца не видит. Элементы с собственной рамкой фокуса
(строка заметки, полоса разделов) используют inset-вариант кольца, чтобы его не обрезал `overflow`.

## 12. Адаптив

| Брейкпоинт | Что происходит |
| --- | --- |
| ≤ 720px (`mobile.css`) | телефон: одна область за раз, полоса разделов → нижняя капсула |

`auto-fit/minmax(min(100%, X), 1fr)` медиазапросам.

**Телефон:**

- Нижнее меню — парящая капсула: `left/right: 12px`, высота `--wb-nav-h: 56px`, отступ

- `100svh`/`100dvh`, а не `100vh` (панель Safari).
- Цели касания ≥ 44px. `-webkit-tap-highlight-color: transparent`, на `(pointer: coarse)`

- `html` красится `--bg-color`, `overscroll-behavior-y: none` — резиновый оттяг не показывает белую дыру.
